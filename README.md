# Runout

Billiard scoring app built with Flutter. Runs on Android, iOS, web, Linux,
macOS, and Windows. The client app scores matches; the manager app is deferred.

## Run

```bash
flutter pub get
flutter run
```

## Build

```bash
flutter build apk
flutter build ios
flutter build web
flutter build linux
flutter build macos
flutter build windows
```
